# Reproducing and validating the package

Use the README quick start on Linux with NVIDIA CUDA. Set `CUDA_LIB_DIR` to your toolkit library directory or the local wheel link directory generated by `scripts/cuda_link_dir.py`. `OSTYAI_CUDART` can explicitly name a runtime shared library. No `/opt/ont/dorado` installation is needed.

The current Rust source is authoritative. Build it locally; the production binary is identified by hash in metadata but not committed. Build stamps, compiler paths and packaging changes mean a new binary hash is expected.

```bash
.venv/bin/python scripts/verify_model.py
.venv/bin/python scripts/verify_benchmarks.py
PYTHONPATH=ostyai .venv/bin/python -m pytest ostyai/test_priority_sampling.py ostyai/test_pool_sampling.py ostyai/test_human_validation.py -q
cd native
cargo nextest run -p sts2-core -p sts2-wire
```

Rust tests use isolated processes because the engine has global hook registries. Avoid a single shared-process `cargo test` run. `cargo test --workspace --doc` is appropriate for doctests. The package verification report separates historical deployment evidence from checks actually rerun on this export.

## Historical step-5500 search

`scripts/evaluate.py` defaults to graph reuse disabled, matching that benchmark's search setting. Current source has the same transition repairs but includes the graph implementation. `provenance/pre-reuse/` retains the three original Rust files needed to reconstruct the pre-reuse search build, and original benchmark provenance retains its binary hash. Do not overwrite published historical summaries with newly computed results.

Asynchronous GPU batching and BF16 kernels can change close decisions. A faithful configuration rerun is not a promise of bitwise trajectory parity; model tensor hashes, fixture bytes, RNG seeds, native revision and configuration must all be recorded. Different hardware/batch order can still differ.

## Benchmark commands

```bash
.venv/bin/python scripts/evaluate.py --suite primary --output results/primary-search
.venv/bin/python scripts/evaluate.py --suite primary --policy-only --output results/primary-policy
.venv/bin/python scripts/evaluate.py --suite human --output results/human-historical-mode
.venv/bin/python scripts/evaluate.py --suite human --reuse --output results/human-current-search
```

Always choose a new output directory. The human suite supports partial-cache reuse only with exact matching provenance. Benchmark fixtures decompress to roughly 1 GB; training data is not downloaded or generated by this step.
